# 원본과 변경 부분

비교 기준은 `baseline/original_v2/`에 보존한 수업 원본 v2다. 현재 애플리케이션은 `all_total_vue_student/`다. 모델 파일·환경 키·세션 DB·임베딩 캐시는 공개 저장소에 포함하지 않는다.

| 구분 | 기존 | 개선 |
|---|---|---|
| 조사 대상 | 모델 작업이 0개일 때만 복구, 기본 auth | 명시 대상 전체와 계획을 대조, 범위 밖 조회 제거 |
| 미등록·미명시 | auth 기본 처리 | 대상 확인 안내로 정책 변경 |
| 장애 매뉴얼 | 전체 알림의 첫 키워드, 불일치 시 db-down | 서비스별 임베딩 검색, 정상·정보 부족이면 검색 생략 |
| 보고 생성 | 자유 서술을 길이·번호로만 검사 | 구조화 필드와 서비스·수치·문서·절차를 검사 |
| 조치 조건 | 모델이 문장을 다시 쓰며 변경 가능 | 선택한 절차를 원문으로 출력 |
| 검증 실패 | 최대 시도 후 강제 통과 | 최대 2회 후 관측·원문 안내로 전환 |
| 응답 제한 | 생성량 상한 없음, 긴 호출 대기 | 512토큰·호출 25초·요청 60초 기본 상한 |
| UI | 채팅·최종 프롬프트 | 서비스별 근거·미확인 사항·진행 과정 추가 |
| 실행 | 포트의 기존 프로세스 종료·DB 삭제 | 사용 중인 포트에서 중단, DB 유지 |

## 변경한 모듈

- `agent/targets.py`: 등록 목록 기준 범위 식별, 계획 보정, 사용자 역할의 이름 선언 식별
- `agent/research.py`: 대상별 조회, 일부 실패 격리, 서비스별 검색·원문 조회
- `agent/retrieval.py`: 임베딩 HTTP 연결, SQLite 캐시·문서 변경 감지, 코사인 검색, MCP 검색 의존성
- `agent/reporting.py`: LLM의 구조화 절차 선택, 오프라인 시험용 명시적 stub
- `agent/validation.py`: 대상 누락·중복·수치 변경·원인 확정·문서 연결·절차 번호 검사
- `agent/evidence.py`: 정상·정보 부족 판단, 근거 payload와 원문 기반 최종 보고
- `agent/nodes.py`, `agent/graph.py`: 주입된 의존성으로 노드 구성, 유한 재작성 분기
- `server.py`: 전체 요청 제한, SSE 종료·메타데이터·SQLite 저장
- `mcp_server.py`: 검색 Tool 추가, 통합 시험용 고정 모의 지표 설정
- `web_chat.html`: 외부 CDN 없는 화면, 근거·미확인 표시, 대화 ID 유지
- `data/runbook_metadata.json`: 기존 매뉴얼의 한·영 증상 설명 보강

## 출력 설계의 제약

서비스·수치·문서 ID·절차 번호를 LLM이 구조화하고 코드가 검증한다. 선택한 문장의 수치와 조건은 모델이 재작성하지 않는다. 이 방식은 자유 생성한 문장 전체의 의미를 검증하는 범용 사실성 평가기가 아니다. 현재 자료 밖의 원인 추론은 제한하고, 원문에 잘못된 절차가 있다면 그대로 전달될 수 있다.

문서가 6개라 벡터는 SQLite에 저장하고 전수 비교한다. 대규모 ANN 검색을 구현한 것은 아니다. 서비스당 Top-1을 연결하므로 같은 서비스의 복합 장애와 미지원 장애의 검색 거절은 추가 검증이 필요하다.

기존 LangGraph·MCP·의존성 주입 기반은 활용했다. 별도의 전문 멀티에이전트나 새로운 LangSmith 연결 검증을 구현했다고 주장하지 않는다. OpenAI 수업 경로는 보존 원본에서 확인할 수 있으며 개선 버전은 Ollama를 검증했다.
