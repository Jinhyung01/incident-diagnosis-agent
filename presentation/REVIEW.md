# 발표 구조 재검토 · 2026-10-22

사용자가 요구한 순서는 최초 질문·응답과 문제 설명, 같은 질문의 개선 결과·구현, 추가 기능별 구현·시연, 정량 비교, 한계다. 최초 사용자 PNG 7개를 모두 본문에서 개선 화면과 연결했다. 이전의 질문 위치 표·중복 화면·보조 검증 슬라이드 10장을 제외하고 표지 포함 26장으로 정리했다.

노트 배분 목표는 297초(4분 57초)이며 실제 구두 리허설은 별도 확인한다. 모든 캡처 문장을 읽으면 목표를 넘으므로 관찰·변경·결과를 중심으로 설명한다.

최초 사진은 무작위 교육용 지표, 개선 시연은 별도 고정 실행이다. CPU·메모리 하락을 성과로 비교하지 않는다. 정량 비교는 별도 고정 질문 20건이며 생성 설정 변경과 안내 응답이 포함된다. 모델은 구조화 JSON을 반환하고 코드가 검증 후 원문으로 구성한다. 확인·실패 안내와 이름 응답은 모델 생성 성공으로 집계하지 않는다.

MCP·RAG·의존성 주입·모듈·단위 테스트는 각 구현 설명과 연결했다. 새 멀티에이전트·LangSmith 성과를 주장하지 않는다. 문서 6개·모의 자료, 검색 지연·오검색, 표현 제약과 시간 상한은 마지막 장에서 설명한다.

원본 사진은 수정하거나 자르지 않는다. 긴 개선 응답은 실제 같은 요청의 연속 화면이다. 실패 전 화면은 별도 원본 재현이며 ReadTimeout은 실행 기록과 대조한다. 지연 주입 시험은 요청 상한 8초, 기본값은 60초다.

이 Mac에는 PowerPoint 앱이 없어 해당 앱과 발표 장비의 직접 실행·글꼴 대체를 확인하지 못했다. 실제 구두 시간과 운영 환경 성능·독립 전문가의 의미 정확도 평가는 별도 확인이 필요하다.

최終版26장 전체를 렌더링하고 개별 화면을 확인했다. 이미지22개·최초PNG7개는 원본 바이트와 같고 이미지 자르기는 없다. 표3개·발표자노트26개, 파일 구조·배치·글꼴·재가져오기와 텍스트 사본 편집 검사를 통과했다. 이는 PowerPoint 앱 직접 실행 검사를 대신하지 않는다.
