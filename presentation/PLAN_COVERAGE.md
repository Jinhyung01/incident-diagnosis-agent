# 원래 계획과 구현·발표 근거

| 계획 | 동작·구현 근거 | PPT |
|---|---|---|
| 자연어 장애 진단 요청 | 모니터링·매뉴얼 보고 | 2~21장 |
| 다중 서비스 조사 | payments·cache와 gateway·payments 각각 조회 | 3~8장 |
| 답변 근거 표시 | 실제 서비스·관측·문서·미확인 사항 | 16·23장 |
| 조사 대상 누락 방지 | 명시 대상과 계획 대조·보완 | 3~8장 |
| 미등록 서비스 처리 | 대체 조회 생략·미명시 대상 확인 | 9~12장 |
| 매뉴얼 선택 개선 | 정상·장애·정보 부족 분기 후 서비스별 검색 | 13~14장 |
| 답변 검증 강화 | 서비스·수치·문서·절차 대조·조건 원문 | 15~16장 |
| 실패 처리 개선 | 생성량·시간 상한·재검증 제한·부분 근거 보존 | 19~21장 |
| RAG 대응 매뉴얼 검색 | bge-m3·SQLite 코사인·MCP 원문 | 22장 |
| 근거·미확인 사항 화면 | 실제 수집 객체로 UI 구성 | 23장 |
| 회귀·동일 입력 비교 | 단위 31개·고정 20건·실제 MCP 별도 검증 | 24~25장 |

개선 5개와 이름·역할 회귀 점검(17~18장)을 설명한 뒤 추가 기능 3개를 따로 설명한다. 최초 사용자 PNG 7개를 모두 본문에 포함했다. 이름·재시작은 추가 주요 기능으로 늘리지 않는다.
