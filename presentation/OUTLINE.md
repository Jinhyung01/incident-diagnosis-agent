# 발표 구성

표지 포함 26장 전체가 발표 본문이다. 최초 질문·응답과 문제를 설명한 바로 다음 장에서 같은 질문의 개선 결과·구현 방식을 설명한다. 개선 설명을 마친 뒤 추가 기능 3개를 각각 구현·실제 동작으로 설명하고, 측정 결과·한계로 마무리한다.

노트 배분 목표는 297초(4분 57초)다. 실제 구두 시간은 측정하지 않았으므로 발표 전 타이머로 확인한다. 긴 캡처 전체를 낭독하지 않고 질문·문제·바꾼 처리와 결과를 짚는다.

최초 사진과 개선 사진은 서로 다른 시점의 실행이다. 수치 자체의 변화는 개선 효과로 비교하지 않는다. 정량 성과는 별도 고정 평가 20건이다. 이름 사례는 대화 회귀 점검이며 추가 주요 기능으로 늘리지 않는다.
