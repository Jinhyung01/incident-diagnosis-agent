# 발표 구성

발표 대상은 같은 과정을 수강한 교육생과 평가자다. 본편 7장, 약 4분 50초를 목표로 한다. 부록은 질문을 받았을 때만 사용한다.

| 순서 | 주제 | 보여줄 근거 | 시간 |
|---|---|---|---:|
| 1 | 운영 장애 진단 에이전트 개선 | 주제와 대표 입력 | 20초 |
| 2 | 요청한 두 서비스 중 하나가 빠졌다 | 원본 조회 기록과 개선 4개·추가 3개 요약 | 40초 |
| 3 | 대상 확인·검색·검증 구조 | 기존 구조와 직접 변경한 경계 | 50초 |
| 4 | 개선된 실제 실행 화면 | 정상 web-01과 auth-service의 매뉴얼 적용 차이 | 45초 |
| 5 | 같은 입력의 개선 전후 | 실제 채팅 화면과 조회 대상 차이 | 40초 |
| 6 | 동일 조건의 비교 결과 | 고정 데이터 20건, 완료율·대상 수집·검색·시간 | 55초 |
| 7 | 한계와 선택 이유 | 검색 지연, 원문 기반 출력 제약, 모의 데이터 | 40초 |

수치는 평가 종료 후 원본 JSON에서 채운다. 응답 완료와 검증 성공을 구분한다. 개선 후 처리 시간은 생성 설정 변경의 영향도 포함하므로 RAG만의 효과라고 설명하지 않는다.

스타일: 16:9, 밝은 바탕·짙은 남색 본문·청록 강조, 한 장에 한 요점. 제목은 짧게 쓰고 수치 표·화면이 중심이 되도록 한다. 본문 설명은 슬라이드에 몰아넣지 않고 발표자 노트로 옮긴다. 외부 템플릿 선택 도구는 제공되지 않아 자료에 맞는 자체 레이아웃으로 만든다.
