# 발표 구성

표지1+본편8(1~9장), 질의용 부록18(10~27장)이다. 본편 노트 목표 합계는 260초(4분20초)이며 실제 구두 리허설 시간과 구분한다. 부록을 이어서 발표하지 않는다.

본편은 표지 → 베이스 프로그램 역할 → 원본 실제 문제 → 같은 질문의 개선 → 구현 → 비교 → 성과와 한계 순서다. 3장의 원본 답변 인용은 실제 캡처와 분리한 읽기 보조 문장이며 이미지를 바꾸지 않았다.

16~17장은 원래10개 시나리오의 목차다. Q05·Q08은 이전 실제 완료 캡처를 재사용했고 나머지는 이번 검토에서 보강했다. Q04·Q06은 각각 두 장의 연속 viewport로 전체 응답을 보여주고 전체 페이지 파일도 보존한다. 원본10개 결과 보고서와 개선UI, 20개 정량평가는 서로 다른 실행이다.
