# 발표 구성

베이스 프로젝트의 역할을 먼저 소개한다. 실제 질문에서 발견한 문제, 코드에서 바꾼 처리, 같은 질문의 결과를 사례별로 설명한 뒤 적용 기술과 추가 기능을 연결한다. 마지막은 선택 정확성 비교와 한계다.

표지 포함25장. 대본 배분294초는 5분 발표를 위한 계획값이며 실제 낭독 시간은 별도 확인한다. 모든 최초 캡처7개와 실제 화면19개를 본문에 유지한다.

|---|---|---:|
