# 실제 MCP·HTTP·SSE 통합 검증

원본 문서의 10개 입력 목적을 개선 정책에 맞춰 검증했다. 실제 로컬 모델·임베딩·MCP subprocess·원본 프록시를 통과했다. 고정 모의 지표를 사용했다.

- 10개 시나리오, 이름 입력/재질문을 포함한 11개 요청의 대상·매뉴얼·SSE 종료·최종 내용 일치 확인
- 최초 모니터링 호출의 의도적 시간 초과를 1회 재시도해 복구
- 별도 SQLite DB와 같은 thread를 유지한 서버 재시작 후 사용자 이름을 올바르게 응답
- 일반 대화는 즉시 답하고 장애 답변은 검증 후 조각을 전송한다. 검증 전 LLM 초안을 실시간 공개하지 않는다.
- 웹 UI 화면 자체는 day2/evidence의 별도 실제 브라우저 캡처로 확인한다.
